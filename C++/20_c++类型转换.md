## 1. 隐式类型转换

编译器自动执行的类型转换，通常发生在以下场景：

### 1.1 数值类型提升

```cpp
int a = 42;
double b = a;        // int -> double，安全，无精度损失
char c = 'A';
int d = c;           // char -> int，提升为 ASCII 值 65
```

### 1.2 算术运算中的提升

```cpp
int x = 10;
double y = 3.14;
auto z = x + y;      // int 先提升为 double，结果是 double 类型 13.14
```

### 1.3 窄化转换（有精度损失风险）

```cpp
double pi = 3.14159;
int n = pi;           // 警告：double -> int，小数部分被截断，n = 3
```

### 1.4 指针转换

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* p = arr;         // 数组名隐式转换为指向首元素的指针
```

### 1.5 布尔转换

```cpp
int val = 10;
bool flag = val;      // 非零值转为 true
void* ptr = nullptr;
bool isNull = ptr;    // nullptr 转为 false
```

## 2. C 风格强制转换

语法：`(目标类型) 表达式`

```cpp
double pi = 3.14159;
int n = (int)pi;         // 截断小数，n = 3
int a = 65;
char c = (char)a;        // 转为字符 'A'
// 危险的指针转换（编译通过但运行时可能出错）
float f = 3.14f;
int* p = (int*)&f;       // 将 float 指针强转为 int 指针，不安全！
// 去掉 const 属性
const int val = 100;
int* p2 = (int*)&val;    // 强制去掉 const，可能引发未定义行为
```

> **问题**：C 风格转换功能过于强大且不明确，编译器无法检查意图，容易导致难以发现的 bug。

## 3. C++ 四大强制转换

C++ 引入了四种命名转换，语义明确，便于查找和审查：

### 3.1 `static_cast`

**最常用的转换**，用于相关类型之间的显式转换，在编译时检查。

#### 基本用法

```cpp
// 数值类型转换
double d = 3.14;
int i = static_cast<int>(d);       // i = 3
// 枚举与整数互转
enum Color { RED, GREEN, BLUE };
int val = static_cast<int>(GREEN); // val = 1
Color c = static_cast<Color>(2);   // c = BLUE
```

#### 类层次结构中的上行转换（安全）

```cpp
class Base {
public:
    virtual void print() { std::cout << "Base" << std::endl; }
};
class Derived : public Base {
public:
    void print() override { std::cout << "Derived" << std::endl; }
    void extra() { std::cout << "Extra" << std::endl; }
};
Derived d;
Base* bp = static_cast<Base*>(&d);    // 上行转换：Derived* -> Base*，安全
Base& br = static_cast<Base&>(d);     // 上行转换：Derived& -> Base&，安全
```

#### 类层次结构中的下行转换（不安全，运行时无检查）

```cpp
Base* base = new Derived();
Derived* dp = static_cast<Derived*>(base);  // 下行转换，编译通过
Base* base2 = new Base();
Derived* dp2 = static_cast<Derived*>(base2); // 危险！base2 实际不是 Derived
// dp2->extra();  // 未定义行为！
```

#### `void*` 转换

```cpp
int x = 42;
void* vp = &x;                            // 任意指针 -> void*
int* ip = static_cast<int*>(vp);          // void* -> int*（需要确保类型一致）
```

---

### 3.2 `dynamic_cast`

专门用于**多态类**层次结构中的**安全下行转换**，运行时检查类型。

#### 指针版本（失败返回 nullptr）

```cpp
class Animal {
public:
    virtual ~Animal() = default;  // 必须有虚函数（虚析构函数即可）
    virtual void speak() { std::cout << "..." << std::endl; }
};
class Dog : public Animal {
public:
    void speak() override { std::cout << "Woof!" << std::endl; }
    void wagTail() { std::cout << "Wagging tail" << std::endl; }
};
class Cat : public Animal {
public:
    void speak() override { std::cout << "Meow!" << std::endl; }
};
Animal* pet = new Dog();
// 安全下行转换
Dog* dog = dynamic_cast<Dog*>(pet);
if (dog) {
    dog->wagTail();              // 安全调用 Dog 特有方法
}
Cat* cat = dynamic_cast<Cat*>(pet);
if (cat) {
    // 不会执行，因为 pet 实际指向的是 Dog
} else {
    std::cout << "pet is not a Cat" << std::endl;
}
```

#### 引用版本（失败抛出 `std::bad_cast`）

```cpp
Animal& petRef = *pet;
try {
    Dog& dogRef = dynamic_cast<Dog&>(petRef);
    dogRef.wagTail();            // 成功执行
} catch (const std::bad_cast& e) {
    std::cout << "Cast failed: " << e.what() << std::endl;
}
try {
    Cat& catRef = dynamic_cast<Cat&>(petRef);
    // 不会执行到这里
} catch (const std::bad_cast& e) {
    std::cout << "Cast failed: " << e.what() << std::endl;  // 抛出异常
}
```

#### 交叉转换（同一继承层级之间的转换）

```cpp
class Animal { virtual ~Animal() = default; };
class Mammal : public Animal {};
class Bird : public Animal {};
class Platypus : public Mammal, public Bird {};
Platypus p;
Mammal* m = &p;
Bird* b = dynamic_cast<Bird*>(m);  // 交叉转换：Mammal* -> Bird*，成功
```

> **注意**：`dynamic_cast` 依赖 RTTI（运行时类型信息），编译器需开启该特性（默认开启，可通过 `-fno-rtti` 关闭）。

---

### 3.3 `const_cast`

**唯一能去除或添加 const/volatile 限定符的转换**。

#### 去除 const

```cpp
void legacyApi(char* str) {
    // 旧版 API 接受非 const 参数，但实际不修改
    std::cout << str << std::endl;
}
const char* msg = "Hello, World!";
legacyApi(const_cast<char*>(msg));  // 安全：legacyApi 不会修改 msg
// 危险用法示例：
const int val = 100;
int* p = const_cast<int*>(&val);
*p = 200;   // 未定义行为！val 原本是 const，可能存储在只读内存区域
```

#### 去除 volatile

```cpp
volatile int sensor = 0;
void readSensor() {
    int value = const_cast<int&>(sensor); // 去除 volatile，读取一次
    // 后续多次使用 value，不会重复从内存读取
}
```

> **核心原则**：`const_cast` 只能用于去除 const 去调用那些本应接受 const 但不修改数据的函数。**永远不要用 `const_cast` 去修改一个原本声明为 const 的对象。**

---

### 3.4 `reinterpret_cast`

最危险的转换，对二进制位模式直接重新解释，**不进行任何类型检查或调整**。

#### 指针与整数互转

```cpp
int x = 42;
int* p = &x;
// 指针转整数（通常用于调试或底层操作）
uintptr_t addr = reinterpret_cast<uintptr_t>(p);
std::cout << "Address: 0x" << std::hex << addr << std::endl;
// 整数转回指针（极度危险，需确保地址有效）
int* q = reinterpret_cast<int*>(addr);  // 仅当 addr 确实指向有效 int 时安全
```

#### 不相关类型指针互转

```cpp
struct A { int a; };
struct B { float b; };
A a{10};
B* pb = reinterpret_cast<B*>(&a);  // 危险！解释 A 的内存布局为 B
```

#### 函数指针互转

```cpp
using FuncPtr = void(*)();
void myFunc() { std::cout << "Hello" << std::endl; }
// 函数指针互转
auto fp = reinterpret_cast<FuncPtr>(myFunc);
fp();  // 可以调用，但类型签名的兼容性由程序员保证
```

#### 网络编程中的序列化用途（合理场景）

```cpp
// 发送数据时，将结构体视为字节流
struct Packet {
    int id;
    float value;
};
Packet pkt{1, 3.14f};
// 将结构体指针转为 char* 以便按字节发送/接收
const char* raw = reinterpret_cast<const char*>(&pkt);
send(socket, raw, sizeof(Packet), 0);
// 接收时，将字节流转回结构体
Packet received;
char* buf = reinterpret_cast<char*>(&received);
recv(socket, buf, sizeof(Packet), 0);
```

## 4. 对比总结

| 转换方式 | 语义 | 运行时检查 | 安全性 | 适用场景 |
| --- | --- | --- | --- | --- |
| **隐式转换** | 编译器自动 | 无 | 中 | 类型提升、安全转换 |
| **C 风格 `(T)expr`** | 不明确 | 无 | 低 | 不推荐使用 |
| **`static_cast`** | 编译时相关类型转换 | 无 | 中高 | 数值转换、上行转换、`void*` 转换 |
| **`dynamic_cast`** | 多态安全下行转换 | **有** | 高 | 继承体系中下行/交叉转换 |
| **`const_cast`** | 去除/添加 cv 限定符 | 无 | 中 | 兼容旧 API、只去除 const 不修改 |
| **`reinterpret_cast`** | 二进制位重新解释 | 无 | **极低** | 底层操作、序列化、硬件编程 |

### 功能覆盖图

```
C 风格转换 (覆盖一切，不推荐)
    │
    ├── static_cast   ← 相关类型编译时转换
    ├── dynamic_cast  ← 多态安全运行时转换（C 风格做不到）
    ├── const_cast    ← cv 限定符专用转换
    └── reinterpret_cast ← 不相关类型二进制转换
```

## 5. 最佳实践

### 5.1 转换选择决策树

```
需要类型转换？
    │
    ├── 编译器能自动安全完成？
    │       └── YES → 使用隐式转换（什么都不做）
    │
    ├── 去除 const/volatile？
    │       └── YES → 使用 const_cast
    │           └── ⚠ 确认被指向的对象本身不是 const
    │
    ├── 多态类层次中的安全下行转换？
    │       └── YES → 使用 dynamic_cast
    │
    ├── 相关类型之间的编译时转换？
    │   （数值类型、枚举、void*、类继承上行）
    │       └── YES → 使用 static_cast
    │
    └── 不相关类型的二进制重新解释？
            └── YES → 使用 reinterpret_cast
                └── ⚠ 最后手段，确认没有其他替代方案
```

### 5.2 核心原则

1. **优先使用隐式转换**：如果编译器能安全完成，不要画蛇添足。

2. **禁止 C 风格转换**：在代码审查中，C 风格转换应被视为潜在 bug。

3. **用 `dynamic_cast` 替代 `static_cast` 做下行转换**：多态场景下使用 `dynamic_cast` 获得运行时安全保障。

4. **封装 `const_cast` 用法**：将去除 const 的操作封装在工具函数中，并添加注释说明原因。

   ```cpp
   // ✅ 好的做法
   void callLegacyApi(const char* str) {
       // legacyFunc 源码确认不会修改参数
       legacyFunc(const_cast<char*>(str));
   }
   // ❌ 坏的做法
   const int MAX = 100;
   int* p = const_cast<int*>(&MAX);  // 永远不要这么做
   *p = 200;  // 未定义行为
   ```

5. **`reinterpret_cast` 加上充分注释**：每次使用都应该解释为什么必须这样做，以及为什么其他转换不适用。

6. **启用编译器警告**：使用 `-Wconversion`、`-Wsign-conversion` 等选项捕获意外的隐式窄化转换。

   ```bash
   g++ -Wall -Wextra -Wconversion -Wsign-conversion main.cpp
   ```
