## C++ 智能指针总结（C++11/14/17）

### 一、三种核心智能指针（C++11 引入）

#### 1. `std::unique_ptr` — 独占所有权

- **所有权模型**：唯一拥有对象，不可复制，只能移动
- **核心特性**：
  - `std::move()` 转移所有权，转移后原指针变为 `nullptr`
  - 零开销（与裸指针大小相同）
  - 可自定义删除器：`unique_ptr<T, D>`
- **适用场景**：默认首选，绝大多数情况应优先使用

```cpp
// C++11 基本用法
std::unique_ptr<int> p1 = std::make_unique<int>(42);  // C++14 才有 make_unique
std::unique_ptr<int> p2 = std::move(p1);  // 移动语义，p1 变为 nullptr

// 自定义删除器
auto deleter = [](FILE* f) { if(f) fclose(f); };
std::unique_ptr<FILE, decltype(deleter)> fp(fopen("a.txt","r"), deleter);

// 数组版本
std::unique_ptr<int[]> arr = std::make_unique<int[]>(10);  // C++14
```

#### 2. `std::shared_ptr` — 共享所有权

- **所有权模型**：多个指针共享同一对象，引用计数管理生命周期
- **核心特性**：
  - 引用计数为 0 时自动销毁对象
  - 控制块（control block）存储引用计数和删除器
  - 可复制、可移动
  - `use_count()` 查看当前引用计数
- **适用场景**：需要多处共享对象、多线程共享资源

```cpp
std::shared_ptr<int> sp1 = std::make_shared<int>(42);
std::shared_ptr<int> sp2 = sp1;  // 引用计数变为 2
sp1.reset();  // sp1 释放，引用计数变为 1，对象不销毁
sp2.reset();  // 引用计数变为 0，对象销毁

// make_shared 比 new 更高效（一次分配同时创建对象和控制块）
auto sp = std::make_shared<std::string>("hello");  // 优于 shared_ptr<string>(new string("hello"))
```

#### 3. `std::weak_ptr` — 弱引用（不参与引用计数）

- **所有权模型**：观察者，不增加引用计数，不控制生命周期
- **核心特性**：
  - 必须从 `shared_ptr` 创建
  - `lock()` 升级为 `shared_ptr`（若对象已销毁则返回空）
  - `expired()` 检查对象是否已销毁
- **适用场景**：打破 `shared_ptr` 循环引用、缓存、观察者模式

```cpp
std::shared_ptr<int> sp = std::make_shared<int>(42);
std::weak_ptr<int> wp = sp;

if (auto locked = wp.lock()) {  // 升级为 shared_ptr
    std::cout << *locked << std::endl;  // 安全访问
} else {
    std::cout << "对象已销毁" << std::endl;
}
```

### 二、各版本新增特性

#### C++11 — 基础框架

| 特性 | 说明 |
|------|------|
| `unique_ptr` | 替代 `auto_ptr`，禁止复制，支持移动 |
| `shared_ptr` | 引用计数共享所有权 |
| `weak_ptr` | 弱引用，解决循环引用 |
| `make_shared` | 高效创建 `shared_ptr` |
| `shared_ptr<T[]>` | 支持数组（但无 `make_shared<T[]>`） |

> ⚠️ **`std::auto_ptr` 在 C++11 中已废弃，C++17 中移除**

#### C++14 — 补充完善

| 特性 | 说明 |
|------|------|
| `make_unique` | 补全了 `unique_ptr` 的工厂函数（C++11 遗漏） |
| `make_unique<T[]>` | 数组版本的 `make_unique` |

```cpp
// C++11 只能用 new（不推荐）
std::unique_ptr<int> p(new int(42));

// C++14 推荐
auto p = std::make_unique<int>(42);
auto arr = std::make_unique<int[]>(10);
```

#### C++17 — 重要增强

| 特性 | 说明 |
|------|------|
| `shared_ptr<T[]>` | **正式支持数组**，且可用 `make_shared<T[]>` |
| `allocate_shared` | 结合自定义分配器的 `shared_ptr` |
| `unique_ptr<T[]>::operator[]` | 数组下标访问 |

```cpp
// C++17 数组 shared_ptr
auto sp_arr = std::make_shared<std::shared_ptr<int>[]>(10);
// C++14 不支持 make_shared<T[]>，需要手动 new
```

### 三、循环引用问题及解决

```cpp
// ❌ 循环引用 → 内存泄漏
struct Node {
    std::shared_ptr<Node> next;
    std::shared_ptr<Node> prev;  // 问题所在
};

// ✅ 用 weak_ptr 打破循环
struct Node {
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;    // 不增加引用计数
};
```

### 四、选择指南

| 场景 | 选择 |
|------|------|
| 默认情况 | `unique_ptr` |
| 需要共享所有权 | `shared_ptr` |
| 需要观察但不拥有 | `weak_ptr` |
| 打破循环引用 | `weak_ptr` |
| 管理动态数组 | `unique_ptr<T[]>` / `shared_ptr<T[]>`(C++17) |
| 自定义资源释放 | `unique_ptr<T, D>` |

---

### 五、最佳实践

1. **优先用 `make_unique` / `make_shared`**，避免裸 `new`
2. **`unique_ptr` 是默认选择**，除非明确需要共享
3. **不要混用裸指针和智能指针**管理同一对象
4. **`shared_ptr` 注意循环引用**，用 `weak_ptr` 打破
5. **避免用 `shared_ptr` 存储 `unique_ptr` 释放的对象**（`shared_ptr` 会用默认 delete 而非 `unique_ptr` 的自定义删除器）
6. **多线程下 `shared_ptr` 引用计数是原子安全的**，但对象访问仍需加锁
