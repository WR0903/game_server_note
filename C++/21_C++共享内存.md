# Linux C++ 进程间共享内存



> 共享内存（Shared Memory）是 **最快** 的进程间通信（IPC）方式。多个进程将同一块物理内存映射到各自的地址空间，读写数据 **无需内核态拷贝**，性能远超管道、消息队列、Socket。

>

> 本文聚焦 Linux 平台，涵盖 POSIX 与 System V 两种方案，配合信号量同步，并给出可直接编译运行的完整示例。

## 一、核心概念



### 1.1 共享内存的本质



```

进程 A 虚拟地址空间             进程 B 虚拟地址空间

   ┌──────────────┐                ┌──────────────┐

   │              │                │              │

   │  0x7f00_0000 │──┐          ┌──│  0x7fa0_0000 │

   │              │  │          │  │              │

   └──────────────┘  │          │  └──────────────┘

                     ▼          ▼

                ┌──────────────────┐

                │   物理内存页      │  ← 同一块物理页

                │   (共享区域)      │

                └──────────────────┘

```



**关键点**：



- 两个进程的虚拟地址可以不同，但都指向同一段物理内存。

- 一方写入，另一方立刻可见（无拷贝、无系统调用开销）。

- **不自带同步机制**，必须配合互斥锁 / 信号量使用。

- 生命周期是 **内核持久** 的：即使所有进程退出，共享内存对象仍然存在，需显式删除。



### 1.2 与其他 IPC 的性能对比



| IPC 方式         | 数据拷贝次数 | 典型延迟     | 适用场景         |
| --- | --- | --- | --- |
| 管道 / FIFO      | 4 次         | ~几十 μs     | 简单流式数据     |
| 消息队列         | 4 次         | ~几十 μs     | 结构化短消息     |
| Unix Domain Sock | 2 次         | ~10 μs       | 本机网络式通信   |
| **共享内存**     | **0 次**     | **~ns 级别** | **高频大数据量** |

## 二、方案对比：POSIX vs System V



| 特性           | POSIX (`shm_open`)              | System V (`shmget`)         |
| --- | --- | --- |
| 标识方式       | 文件名（如 `/my_shm`）          | `key_t`（通过 `ftok` 生成） |
| 头文件         | `<sys/mman.h>` `<fcntl.h>`      | `<sys/shm.h>`               |
| 编译链接       | `-lrt`（部分老系统）            | 无需额外链接                |
| 底层           | 挂载在 `/dev/shm` (tmpfs)       | 内核管理，独立表            |
| 查看命令       | `ls /dev/shm/`                  | `ipcs -m`                   |
| 删除命令       | `rm /dev/shm/xxx` 或 `shm_unlink` | `ipcrm -m` 或 `shmctl`      |
| 与 mmap 集成   | 天然结合                        | 不能直接 mmap               |
| 推荐度         | ⭐⭐⭐⭐⭐ **首选**                 | ⭐⭐⭐（老代码维护）           |



**结论**：新项目一律使用 **POSIX** 方案。System V 只在维护老代码时使用。

## 三、POSIX 共享内存：`shm_open` + `mmap`



### 3.1 API 概览



```cpp

#include <sys/mman.h>   // mmap, munmap, shm_open, shm_unlink

#include <sys/stat.h>   // mode 常量

#include <fcntl.h>      // O_* 常量

#include <unistd.h>     // ftruncate, close



// 1. 创建/打开共享内存对象（返回 fd）

int shm_open(const char *name, int oflag, mode_t mode);



// 2. 调整大小（首次创建必须调用）

int ftruncate(int fd, off_t length);



// 3. 映射到进程地址空间

void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);



// 4. 解除映射

int munmap(void *addr, size_t length);



// 5. 删除共享内存对象（引用计数为 0 时真正释放）

int shm_unlink(const char *name);

```



**参数说明**：



- `name`：以 `/` 开头的字符串，如 `"/my_shared_mem"`，实际会创建 `/dev/shm/my_shared_mem`。

- `oflag`：`O_CREAT | O_RDWR`（创建者），`O_RDWR`（后续访问者）。

- `mode`：权限，常用 `0666`。

- `prot`：`PROT_READ | PROT_WRITE`。

- `flags`：`MAP_SHARED`（必须，否则修改不共享）。



### 3.2 完整示例：Writer 进程



**`shm_writer.cpp`** —— 创建共享内存并写入数据



```cpp

#include <iostream>

#include <cstring>

#include <sys/mman.h>

#include <sys/stat.h>

#include <fcntl.h>

#include <unistd.h>

#include <chrono>

#include <thread>



// 共享的数据结构（进程间必须字节对齐一致）

struct SharedData {

    int  counter;

    char message[256];

    double timestamp;

};



constexpr const char* SHM_NAME = "/demo_shm";

constexpr size_t SHM_SIZE = sizeof(SharedData);



int main() {

    // 1. 创建共享内存对象

    int fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);

    if (fd == -1) {

        perror("shm_open");

        return 1;

    }



    // 2. 设置大小

    if (ftruncate(fd, SHM_SIZE) == -1) {

        perror("ftruncate");

        close(fd);

        return 1;

    }



    // 3. 映射到当前进程地址空间

    void* ptr = mmap(nullptr, SHM_SIZE,

                     PROT_READ | PROT_WRITE,

                     MAP_SHARED, fd, 0);

    if (ptr == MAP_FAILED) {

        perror("mmap");

        close(fd);

        return 1;

    }



    // fd 在 mmap 后即可关闭，映射依然有效

    close(fd);



    // 4. 使用共享内存

    auto* data = static_cast<SharedData*>(ptr);

    std::memset(data, 0, SHM_SIZE);



    std::cout << "[Writer] PID=" << getpid()

              << " 开始写入共享内存 " << SHM_NAME << std::endl;



    for (int i = 1; i <= 20; ++i) {

        data->counter = i;

        std::snprintf(data->message, sizeof(data->message),

                      "Hello from writer, msg #%d", i);

        data->timestamp = std::chrono::duration<double>(

            std::chrono::system_clock::now().time_since_epoch()).count();



        std::cout << "[Writer] 写入 counter=" << i << std::endl;

        std::this_thread::sleep_for(std::chrono::seconds(1));

    }



    // 5. 解除映射

    munmap(ptr, SHM_SIZE);



    // 6. 由 Writer 负责删除共享内存对象

    //    （若不 unlink，重启后仍会存在于 /dev/shm）

    shm_unlink(SHM_NAME);



    std::cout << "[Writer] 完成，已删除共享内存" << std::endl;

    return 0;

}

```



### 3.3 完整示例：Reader 进程



**`shm_reader.cpp`** —— 读取共享内存



```cpp

#include <iostream>

#include <sys/mman.h>

#include <fcntl.h>

#include <unistd.h>

#include <chrono>

#include <thread>



struct SharedData {

    int  counter;

    char message[256];

    double timestamp;

};



constexpr const char* SHM_NAME = "/demo_shm";

constexpr size_t SHM_SIZE = sizeof(SharedData);



int main() {

    // 1. 打开已存在的共享内存（不加 O_CREAT）

    int fd = shm_open(SHM_NAME, O_RDONLY, 0666);

    if (fd == -1) {

        perror("shm_open (请先运行 writer)");

        return 1;

    }



    // 2. 映射为只读

    void* ptr = mmap(nullptr, SHM_SIZE,

                     PROT_READ,

                     MAP_SHARED, fd, 0);

    if (ptr == MAP_FAILED) {

        perror("mmap");

        close(fd);

        return 1;

    }

    close(fd);



    const auto* data = static_cast<const SharedData*>(ptr);

    std::cout << "[Reader] PID=" << getpid()

              << " 开始读取共享内存" << std::endl;



    int last_counter = -1;

    for (int i = 0; i < 30; ++i) {

        if (data->counter != last_counter) {

            std::cout << "[Reader] counter=" << data->counter

                      << " msg=\"" << data->message << "\""

                      << " ts=" << data->timestamp << std::endl;

            last_counter = data->counter;

        }

        std::this_thread::sleep_for(std::chrono::milliseconds(500));

    }



    munmap(const_cast<void*>(ptr), SHM_SIZE);

    // Reader 不 unlink，让 Writer 负责清理

    return 0;

}

```

```bash

g++ -std=c++17 -O2 -o reader shm_reader.cpp -lrt -lpthread



# 终端 1：启动写进程

./writer



# 终端 2：立刻启动读进程

./reader



# 查看共享内存对象

```

## 四、System V 共享内存：`shmget` + `shmat`



> 老系统或旧代码维护会用到，新项目请用 POSIX。



### 4.1 API 概览



```cpp

#include <sys/ipc.h>

#include <sys/shm.h>



key_t ftok(const char *pathname, int proj_id);          // 生成 key

int   shmget(key_t key, size_t size, int shmflg);       // 创建/获取

void* shmat (int shmid, const void *shmaddr, int flag); // 附加到进程

int   shmdt (const void *shmaddr);                      // 分离

int   shmctl(int shmid, int cmd, struct shmid_ds *buf); // 控制/删除

```



### 4.2 Writer 示例



**`sysv_writer.cpp`**



```cpp

#include <iostream>

#include <cstring>

#include <sys/ipc.h>

#include <sys/shm.h>

#include <unistd.h>

#include <chrono>

#include <thread>



struct SharedData {

    int  counter;

    char message[256];

};



int main() {

    // 1. 生成 key（依赖真实存在的文件路径）

    key_t key = ftok("/tmp", 'A');

    if (key == -1) { perror("ftok"); return 1; }



    // 2. 创建共享内存段

    int shmid = shmget(key, sizeof(SharedData), IPC_CREAT | 0666);

    if (shmid == -1) { perror("shmget"); return 1; }



    // 3. 附加到当前进程

    void* ptr = shmat(shmid, nullptr, 0);

    if (ptr == (void*)-1) { perror("shmat"); return 1; }



    auto* data = static_cast<SharedData*>(ptr);

    std::memset(data, 0, sizeof(SharedData));



    for (int i = 1; i <= 10; ++i) {

        data->counter = i;

        std::snprintf(data->message, sizeof(data->message),

                      "SysV msg #%d", i);

        std::cout << "[Writer] 写入 counter=" << i << std::endl;

        std::this_thread::sleep_for(std::chrono::seconds(1));

    }



    // 4. 分离

    shmdt(ptr);



    // 5. 标记删除（所有进程 detach 后才真正释放）

    shmctl(shmid, IPC_RMID, nullptr);

    return 0;

}

```



### 4.3 Reader 示例



**`sysv_reader.cpp`**

```cpp
#include <sys/ipc.h>

#include <sys/shm.h>

    }



    shmdt(ptr);

    return 0;

}
```

## 五、同步机制：POSIX 命名信号量



共享内存本身不保证并发安全，必须配合同步原语。**POSIX 命名信号量** 与 POSIX 共享内存搭配最自然。



### 5.1 API



```cpp

#include <semaphore.h>

#include <fcntl.h>



sem_t* sem_open(const char *name, int oflag, mode_t mode, unsigned int value);

int    sem_wait(sem_t *sem);      // P 操作：-1，为 0 时阻塞

int    sem_post(sem_t *sem);      // V 操作：+1

int    sem_close(sem_t *sem);

int    sem_unlink(const char *name);

```



命名信号量文件位于 `/dev/shm/sem.<name>`。



### 5.2 加锁访问共享内存



**`shm_sync_writer.cpp`**



```cpp

#include <iostream>

#include <cstring>

#include <sys/mman.h>

#include <sys/stat.h>

#include <fcntl.h>

#include <unistd.h>

#include <semaphore.h>

#include <chrono>

#include <thread>



struct SharedData {

    int  counter;

    char message[256];

};



constexpr const char* SHM_NAME = "/demo_sync_shm";

constexpr const char* SEM_NAME = "/demo_sync_sem";



int main() {

    // 1. 创建共享内存

    int fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);

    ftruncate(fd, sizeof(SharedData));

    auto* data = static_cast<SharedData*>(

        mmap(nullptr, sizeof(SharedData),

             PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0));

    close(fd);



    // 2. 创建信号量（初值 1，相当于互斥锁）

    sem_t* sem = sem_open(SEM_NAME, O_CREAT, 0666, 1);

    if (sem == SEM_FAILED) { perror("sem_open"); return 1; }



    std::memset(data, 0, sizeof(SharedData));



    for (int i = 1; i <= 10; ++i) {

        sem_wait(sem);   // P：加锁

        // ============= 临界区开始 =============

        data->counter = i;

        std::snprintf(data->message, sizeof(data->message),

                      "safe msg #%d", i);

        std::cout << "[Writer] wrote " << i << std::endl;

        // ============= 临界区结束 =============

        sem_post(sem);   // V：解锁



        std::this_thread::sleep_for(std::chrono::milliseconds(500));

    }



    munmap(data, sizeof(SharedData));

    sem_close(sem);



    // 清理

    shm_unlink(SHM_NAME);

    sem_unlink(SEM_NAME);

    return 0;

}

```



**`shm_sync_reader.cpp`**



```cpp

#include <iostream>

#include <sys/mman.h>

#include <fcntl.h>

#include <unistd.h>

#include <semaphore.h>

#include <chrono>

#include <thread>



struct SharedData {

    int  counter;

    char message[256];

};



constexpr const char* SHM_NAME = "/demo_sync_shm";

constexpr const char* SEM_NAME = "/demo_sync_sem";



int main() {

    int fd = shm_open(SHM_NAME, O_RDWR, 0666);

    if (fd == -1) { perror("shm_open"); return 1; }



    auto* data = static_cast<SharedData*>(

        mmap(nullptr, sizeof(SharedData),

             PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0));

    close(fd);



    sem_t* sem = sem_open(SEM_NAME, 0);

    if (sem == SEM_FAILED) { perror("sem_open"); return 1; }



    int last = -1;

    for (int i = 0; i < 40; ++i) {

        sem_wait(sem);

        int cur = data->counter;

        std::string msg = data->message;

        sem_post(sem);



        if (cur != last) {

            std::cout << "[Reader] counter=" << cur

                      << " msg=\"" << msg << "\"" << std::endl;

            last = cur;

        }

        std::this_thread::sleep_for(std::chrono::milliseconds(200));

    }



    munmap(data, sizeof(SharedData));

    sem_close(sem);

    return 0;

}

```

### 5.3 进程间互斥锁（放入共享内存）



如果想用 `pthread_mutex_t` 代替信号量，需要将 mutex **本身放在共享内存里**，并设置 `PTHREAD_PROCESS_SHARED` 属性：



```cpp

pthread_mutexattr_t attr;

pthread_mutexattr_init(&attr);

pthread_mutexattr_setpshared(&attr, PTHREAD_PROCESS_SHARED);

// 注意：mutex 必须位于共享内存区域内

pthread_mutex_init(&shared_ptr->mutex, &attr);

pthread_mutexattr_destroy(&attr);

```



条件变量类似，使用 `PTHREAD_PROCESS_SHARED` + `pthread_cond_t`。

## 六、实战案例：环形缓冲区（生产者-消费者）



**场景**：一个生产者进程写数据，多个消费者进程读取，实现无锁或轻锁的环形队列。



### 6.1 共享结构定义



**`ring_buffer.hpp`**



```cpp

#pragma once

#include <atomic>

#include <cstdint>

#include <cstring>



constexpr size_t RING_CAPACITY = 1024;   // 必须是 2 的幂

constexpr size_t ITEM_SIZE     = 128;



struct RingBuffer {

    // 使用 atomic 保证内存序，多进程可见

    alignas(64) std::atomic<uint64_t> head;   // 生产者写位置

    alignas(64) std::atomic<uint64_t> tail;   // 消费者读位置

    alignas(64) char slots[RING_CAPACITY][ITEM_SIZE];



    bool push(const char* data, size_t len) {

        uint64_t h = head.load(std::memory_order_relaxed);

        uint64_t t = tail.load(std::memory_order_acquire);

        if (h - t >= RING_CAPACITY) return false;   // 满



        size_t idx = h & (RING_CAPACITY - 1);

        size_t n = std::min(len, ITEM_SIZE - 1);

        std::memcpy(slots[idx], data, n);

        slots[idx][n] = '\0';



        head.store(h + 1, std::memory_order_release);

        return true;

    }



    bool pop(char* out, size_t out_len) {

        uint64_t t = tail.load(std::memory_order_relaxed);

        uint64_t h = head.load(std::memory_order_acquire);

        if (t == h) return false;   // 空



        size_t idx = t & (RING_CAPACITY - 1);

        std::strncpy(out, slots[idx], out_len);



        tail.store(t + 1, std::memory_order_release);

        return true;

    }

};



static_assert(sizeof(RingBuffer) < 200 * 1024, "ring too large");

```



> 说明：单生产者-单消费者场景下无需锁；多生产者/多消费者需将 `head/tail` 的更新改为 `compare_exchange_weak`，或加信号量。



### 6.2 生产者



**`producer.cpp`**



```cpp

#include "ring_buffer.hpp"

#include <iostream>

#include <sys/mman.h>

#include <sys/stat.h>

#include <fcntl.h>

#include <unistd.h>

#include <chrono>

#include <thread>



constexpr const char* SHM_NAME = "/demo_ring";



int main() {

    int fd = shm_open(SHM_NAME, O_CREAT | O_RDWR, 0666);

    ftruncate(fd, sizeof(RingBuffer));



    auto* ring = static_cast<RingBuffer*>(

        mmap(nullptr, sizeof(RingBuffer),

             PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0));

    close(fd);



    // 初始化（仅第一次运行时清零）

    ring->head.store(0);

    ring->tail.store(0);



    for (int i = 0; i < 100; ++i) {

        char buf[64];

        std::snprintf(buf, sizeof(buf), "item-%d pid=%d", i, getpid());

        while (!ring->push(buf, std::strlen(buf))) {

            std::this_thread::sleep_for(std::chrono::milliseconds(1));

        }

        std::cout << "[P] push: " << buf << std::endl;

        std::this_thread::sleep_for(std::chrono::milliseconds(50));

    }



    munmap(ring, sizeof(RingBuffer));

    // 注意：这里不 unlink，方便反复演示；正式使用完毕再 shm_unlink

    return 0;

}

```



### 6.3 消费者

```cpp
    char buf[ITEM_SIZE];

    for (int i = 0; i < 100; ++i) {

        while (!ring->pop(buf, sizeof(buf))) {

            std::this_thread::sleep_for(std::chrono::milliseconds(5));

        }

        std::cout << "[C pid=" << getpid() << "] got: " << buf << std::endl;

    }



    munmap(ring, sizeof(RingBuffer));

    return 0;

}

```

## 七、C++ RAII 封装



手动管理 `shm_open` / `mmap` / `munmap` / `shm_unlink` 易出错。用 RAII 封装成模板类：



**`shared_memory.hpp`**



```cpp

#pragma once

#include <string>

#include <stdexcept>

#include <sys/mman.h>

#include <sys/stat.h>

#include <fcntl.h>

#include <unistd.h>

#include <cstring>



template <typename T>

class SharedMemory {

public:

    // owner=true 表示由本对象负责创建与最终删除

    SharedMemory(const std::string& name, bool owner)

        : name_(name), owner_(owner) {

        int flags = owner ? (O_CREAT | O_RDWR) : O_RDWR;

        fd_ = ::shm_open(name_.c_str(), flags, 0666);

        if (fd_ == -1) throw std::runtime_error("shm_open failed: " + name_);



        if (owner_) {

            if (::ftruncate(fd_, sizeof(T)) == -1) {

                ::close(fd_);

                throw std::runtime_error("ftruncate failed");

            }

        }



        void* p = ::mmap(nullptr, sizeof(T),

                         PROT_READ | PROT_WRITE, MAP_SHARED, fd_, 0);

        if (p == MAP_FAILED) {

            ::close(fd_);

            throw std::runtime_error("mmap failed");

        }

        ptr_ = static_cast<T*>(p);



        if (owner_) std::memset(ptr_, 0, sizeof(T));

    }



    ~SharedMemory() {

        if (ptr_) ::munmap(ptr_, sizeof(T));

        if (fd_ != -1) ::close(fd_);

        if (owner_) ::shm_unlink(name_.c_str());

    }



    // 禁止拷贝

    SharedMemory(const SharedMemory&) = delete;

    SharedMemory& operator=(const SharedMemory&) = delete;



    T*       get()       { return ptr_; }

    const T* get() const { return ptr_; }

    T*       operator->()       { return ptr_; }

    const T* operator->() const { return ptr_; }

    T&       operator*()        { return *ptr_; }

    const T& operator*()  const { return *ptr_; }



private:

    std::string name_;

    bool  owner_ = false;

    int   fd_    = -1;

    T*    ptr_   = nullptr;

};

```



**使用示例**：



```cpp

struct Config {

    int  version;

    char host[128];

    int  port;

};



int main() {

    try {

        SharedMemory<Config> shm("/app_config", /*owner=*/true);

        shm->version = 1;

        std::strcpy(shm->host, "127.0.0.1");

        shm->port = 8080;

        // 析构时自动 unmap + unlink

    } catch (const std::exception& e) {

        std::cerr << e.what() << std::endl;

    }

}

```

## 八、常见坑与最佳实践



### 8.1 生命周期管理



| 坑                                        | 解决方法                              |
| --- | --- |
| 程序崩溃后 `/dev/shm/xxx` 残留            | 启动时先 `shm_unlink` 再创建          |
| 多个进程都不 `unlink`，越攒越多           | 明确一个进程作为 owner，退出前清理    |
| Writer 先退出且 unlink，Reader 段错误     | 只 unlink 名字，映射页仍有效直到 munmap |



**推荐启动模板**：



```cpp

shm_unlink(NAME);   // 忽略错误，先清理残留

int fd = shm_open(NAME, O_CREAT | O_EXCL | O_RDWR, 0666);

```



### 8.2 结构体设计



- **不要在共享内存中放指针**：不同进程虚拟地址不同，指针无效。用 **偏移量** 或 **数组下标** 代替。

- **不要放 `std::string`、`std::vector`**：它们内部有堆指针。改用 `char[N]` 或自定义定长结构。

- **考虑字节对齐**：不同编译器 / 架构对齐规则可能不同，跨语言/跨编译器共享时用 `#pragma pack` 或显式填充。

- **版本字段**：预留 `uint32_t version` 便于协议升级。



### 8.3 并发安全



- 单读单写的简单标量：可用 `std::atomic<T>`（要求 `is_lock_free`）。

- 复杂结构：必须加锁（信号量 / 进程共享 mutex）。

- 使用 `pthread_mutex_t` 时务必：

  - 设置 `PTHREAD_PROCESS_SHARED`

  - 设置 `PTHREAD_MUTEX_ROBUST`（避免持锁进程崩溃后死锁）



### 8.4 权限与容量



- `/dev/shm` 默认大小是 **物理内存的 50%**，可用 `df -h /dev/shm` 查看。

- 修改：`mount -o remount,size=2G /dev/shm` 或改 `/etc/fstab`。

- 权限：`0666` 允许任何用户，生产环境应设为 `0660` + 相同 group。



### 8.5 编译链接



```bash

# POSIX shm/sem 在 glibc 2.34+ 已合并到 libc；老系统需要：

g++ ... -lrt -lpthread

```

## 总结



| 场景                       | 推荐方案                                        |
| --- | --- |
| **新项目、简单共享数据**   | POSIX `shm_open` + `mmap` + 命名信号量          |
| **高性能队列**             | POSIX + `std::atomic` 环形缓冲                  |
| **复杂对象、容器**         | Boost.Interprocess（可扩展阅读）                |
| **老代码维护**             | System V `shmget`                               |



**核心口诀**：



1. 共享内存 = **速度快**，同步机制 = **别忘加**。

2. 别放指针 / STL 容器，用 **POD** 结构。

3. Owner 进程负责 **创建 + 最终 unlink**。

4. 崩溃恢复：启动前 `shm_unlink`，锁用 `ROBUST`。



配合本文示例代码，你可以在 10 分钟内跑通两个进程共享数据的完整链路。
