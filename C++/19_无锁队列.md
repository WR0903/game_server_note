# C++ 无锁队列（Lock-Free Queue）



---



## 一、基本概念



### 1.1 什么是无锁队列



无锁队列（Lock-Free Queue）是一种不依赖互斥锁（mutex）来实现线程安全的并发队列。它基于**原子操作**和**CAS（Compare-And-Swap）**指令，确保在多线程环境下至少有一个线程可以在有限步骤内完成操作，避免死锁、优先级反转等问题。



### 1.2 无锁编程的核心保证



| 级别 | 含义 |
| --- | --- |
| **Wait-Free** | 所有线程在有限步骤内完成操作（最强） |
| **Lock-Free** | 至少有一个线程在有限步骤内完成操作 |
| **Obstruction-Free** | 单线程执行时能在有限步骤内完成（最弱） |



### 1.3 内存序（Memory Order）



无锁编程中最重要的概念之一。C++11 提供了六种内存序：



| 内存序 | 说明 |
| --- | --- |
| `memory_order_relaxed` | 仅保证原子性，无同步/排序约束 |
| `memory_order_consume` | 依赖数据的同步（不推荐使用） |
| `memory_order_acquire` | 读操作，后续读写不能重排到此操作前 |
| `memory_order_release` | 写操作，之前的读写不能重排到此操作后 |
| `memory_order_acq_rel` | 兼具 acquire 和 release 语义 |
| `memory_order_seq_cst` | 顺序一致性（最严格，默认） |



### 1.4 CAS（Compare-And-Swap）



CAS 是无锁队列的核心原语：



```cpp

// CAS 伪代码

bool CAS(T* addr, T expected, T desired) {

    if (*addr == expected) {

        *addr = desired;

        return true;

    }

    return false;

}

```



C++ 中对应的标准库函数：



```cpp

// weak 版本可能发生伪失败（spurious failure），适合在循环中使用

atomic<T>::compare_exchange_weak(T& expected, T desired, memory_order...);



// strong 版本保证只有值不等时才失败

atomic<T>::compare_exchange_strong(T& expected, T desired, memory_order...);

```

## 二、经典实现



### 2.1 单生产者单消费者队列（SPSC）



> 最简单的无锁队列，适用于单生产者、单消费者的场景。



```cpp

#include <atomic>

#include <vector>



template <typename T>

class SPSCQueue {

public:

    explicit SPSCQueue(size_t capacity)

        : capacity_(capacity + 1),   // 多分配一个槽位区分空/满

          buffer_(new T[capacity + 1]),

          write_pos_(0),

          read_pos_(0) {}



    ~SPSCQueue() { delete[] buffer_; }



    SPSCQueue(const SPSCQueue&) = delete;

    SPSCQueue& operator=(const SPSCQueue&) = delete;



    bool enqueue(const T& item) {

        const size_t w = write_pos_.load(std::memory_order_relaxed);

        const size_t r = read_pos_.load(std::memory_order_acquire);

        const size_t next = (w + 1) % capacity_;



        if (next == r) return false;  // 队列已满



        buffer_[w] = item;

        write_pos_.store(next, std::memory_order_release);

        return true;

    }



    bool dequeue(T& item) {

        const size_t r = read_pos_.load(std::memory_order_relaxed);

        const size_t w = write_pos_.load(std::memory_order_acquire);



        if (r == w) return false;  // 队列为空



        item = buffer_[r];

        const size_t next = (r + 1) % capacity_;

        read_pos_.store(next, std::memory_order_release);

        return true;

    }



private:

    const size_t capacity_;

    T* buffer_;



    // 写入端缓存行对齐，避免 false sharing

    alignas(64) std::atomic<size_t> write_pos_;

    alignas(64) std::atomic<size_t> read_pos_;

};

```



**关键设计点：**

- 多分配一个元素槽位，用 `(write + 1) % capacity == read` 判断满

- `read_pos_` 只用 `acquire` 读，`write_pos_` 只用 `release` 写，减少同步开销

- 写入端和读取端分别独占，无需 CAS

### 2.2 多生产者多消费者队列（MPMC）



> 基于数组的环形缓冲区，支持多生产者多消费者。



```cpp

#include <atomic>

#include <vector>

#include <memory>



template <typename T>

class MPMCQueue {

    struct Slot {

        std::atomic<size_t> turn;

        T data;

    };



public:

    explicit MPMCQueue(size_t capacity)

        : capacity_(capacity),

          mask_(capacity - 1),

          slots_(new Slot[capacity]) {

        for (size_t i = 0; i < capacity_; ++i) {

            slots_[i].turn.store(i, std::memory_order_relaxed);

        }

    }



    ~MPMCQueue() { delete[] slots_; }



    MPMCQueue(const MPMCQueue&) = delete;

    MPMCQueue& operator=(const MPMCQueue&) = delete;



    bool enqueue(const T& item) {

        size_t head = head_.load(std::memory_order_relaxed);

        for (;;) {

            Slot& slot = slots_[head & mask_];

            size_t turn = slot.turn.load(std::memory_order_acquire);



            if (turn == head) {

                // 尝试抢占写入位置

                if (head_.compare_exchange_weak(head, head + 1,

                        std::memory_order_relaxed)) {

                    // 成功抢到位置，写入数据

                    slot.data = item;

                    slot.turn.store(head + 1, std::memory_order_release);

                    return true;

                }

            } else if (turn < head) {

                return false;  // 队列已满

            } else {

                head = head_.load(std::memory_order_relaxed);

            }

        }

    }



    bool dequeue(T& item) {

        size_t tail = tail_.load(std::memory_order_relaxed);

        for (;;) {

            Slot& slot = slots_[tail & mask_];

            size_t turn = slot.turn.load(std::memory_order_acquire);



            if (turn == tail + 1) {

                if (tail_.compare_exchange_weak(tail, tail + 1,

                        std::memory_order_relaxed)) {

                    item = slot.data;

                    slot.turn.store(tail + capacity_,

                                    std::memory_order_release);

                    return true;

                }

            } else if (turn < tail + 1) {

                return false;  // 队列为空

            } else {

                tail = tail_.load(std::memory_order_relaxed);

            }

        }

    }



private:

    const size_t capacity_;

    const size_t mask_;                // capacity_ 必须是 2 的幂



    alignas(64) std::atomic<size_t> head_{0};  // 生产者索引

    alignas(64) std::atomic<size_t> tail_{0};  // 消费者索引

    Slot* slots_;

};

```



**关键设计点：**

- 使用 `turn` 序号机制，每个槽位用一个自增序号控制读写权限

- `capacity_` 必须是 2 的幂，用位运算 `& mask_` 代替取模提高性能

- `head_` 和 `tail_` 用 `cacheline` 对齐避免伪共享

### 2.3 基于链表的多生产者多消费者队列



> Michael & Scott 无锁队列（MS-Queue），经典的链表式无锁队列。



```cpp

#include <atomic>

#include <memory>



template <typename T>

class MSQueue {

    struct Node {

        T data;

        std::atomic<Node*> next;

        Node() : next(nullptr) {}

        explicit Node(const T& val) : data(val), next(nullptr) {}

    };



public:

    MSQueue() {

        Node* dummy = new Node();

        head_.store(dummy, std::memory_order_relaxed);

        tail_.store(dummy, std::memory_order_relaxed);

    }



    ~MSQueue() {

        while (Node* node = head_.load()) {

            head_.store(node->next.load());

            delete node;

        }

    }



    MSQueue(const MSQueue&) = delete;

    MSQueue& operator=(const MSQueue&) = delete;



    void enqueue(const T& item) {

        Node* node = new Node(item);



        for (;;) {

            Node* last = tail_.load(std::memory_order_acquire);

            Node* next = last->next.load(std::memory_order_acquire);



            if (last == tail_.load(std::memory_order_acquire)) {

                if (next == nullptr) {

                    // 尝试把新节点链到尾部

                    if (last->next.compare_exchange_weak(

                            next, node, std::memory_order_release,

                            std::memory_order_relaxed)) {

                        // 更新 tail 指针（即使失败也无妨，其他线程会帮助完成）

                        tail_.compare_exchange_weak(

                            last, node, std::memory_order_release,

                            std::memory_order_relaxed);

                        return;

                    }

                } else {

                    // 帮助推进 tail

                    tail_.compare_exchange_weak(

                        last, next, std::memory_order_release,

                        std::memory_order_relaxed);

                }

            }

        }

    }



    bool dequeue(T& item) {

        for (;;) {

            Node* first = head_.load(std::memory_order_acquire);

            Node* last  = tail_.load(std::memory_order_acquire);

            Node* next  = first->next.load(std::memory_order_acquire);



            if (first == head_.load(std::memory_order_acquire)) {

                if (first == last) {

                    if (next == nullptr) {

                        return false;  // 队列为空

                    }

                    // 帮助推进 tail

                    tail_.compare_exchange_weak(

                        last, next, std::memory_order_release,

                        std::memory_order_relaxed);

                } else {

                    // 读取数据

                    item = next->data;

                    if (head_.compare_exchange_weak(

                            first, next, std::memory_order_release,

                            std::memory_order_relaxed)) {

                        break;

                    }

                }

            }

        }

        // 删除旧头节点（可延迟回收）

        // 注意：此处在真实场景需要安全的节点回收策略

        return true;

    }



private:

    alignas(64) std::atomic<Node*> head_;

    alignas(64) std::atomic<Node*> tail_;

};

```

## 三、内存回收问题



无锁队列中的一大难点是**安全地释放节点内存**，即 **ABA 问题** 和 **Memory Reclamation**。



### 3.1 ABA 问题



```

时间线：

线程 A：读取 head = 0x1000（指向节点 X）

线程 B：pop 节点 X，释放 X

线程 B：push 新节点，恰好分配到 0x1000（节点 Y）

线程 A：CAS head 从 0x1000 到 0x1000->next  —— 成功！但语义错误

```



**解决方案：**



| 方案 | 原理 | 优缺点 |
| --- | --- | --- |
| **Tagged Pointer** | 指针 + 版本号组成双字 CAS | 需要处理器支持 DCAS，有限制 |
| **Hazard Pointer** | 线程声明"我正在使用"的指针，延迟释放 | 标准方案，性能好 |
| **RCU** | 读端无锁，写端延迟回收 | 适用于读多写少 |
| **Epoch-Based GC** | 基于 epoch 的批量回收 | 高性能，批量延迟 |



### 3.2 Hazard Pointer 示例



```cpp

#include <atomic>

#include <array>

#include <functional>



template <typename T, size_t MaxHazards = 2>

class HazardPointer {

    struct HP {

        std::atomic<T*> ptr{nullptr};

    };



    std::array<HP, MaxThreads> hazards_;

    std::vector<T*> retire_list_;



public:

    T* protect(size_t hp_index, const std::atomic<T*>& ptr) {

        T* p;

        do {

            p = ptr.load(std::memory_order_acquire);

            hazards_[thread_id][hp_index].store(p, std::memory_order_release);

        } while (p != ptr.load(std::memory_order_acquire));

        return p;

    }



    void clear(size_t hp_index) {

        hazards_[thread_id][hp_index].store(nullptr, std::memory_order_release);

    }



    void retire(T* ptr) {

        retire_list_.push_back(ptr);

        if (retire_list_.size() >= batch_size) {

            scan_and_reclaim();

        }

    }

};

```

## 四、性能优化技巧



### 4.1 缓存行对齐（避免 False Sharing）



```cpp

// 将共享变量分散到不同缓存行（通常 64 字节）

alignas(64) std::atomic<size_t> write_pos_;

alignas(64) std::atomic<size_t> read_pos_;

```



当两个线程分别写 `write_pos_` 和读 `read_pos_` 时，它们位于不同缓存行，避免缓存一致性协议带来的性能抖动。



### 4.2 容量设置为 2 的幂



```cpp

// 取模运算 → 位运算

size_t index = pos & (capacity_ - 1);   // 替代 pos % capacity_

```



### 4.3 合理选择内存序



```cpp

// 写入端：只需 release，确保数据先于位置更新可见

buffer_[w] = item;

write_pos_.store(next, std::memory_order_release);



// 读取端：只需 acquire，确保读到位置更新后能看见数据

size_t w = write_pos_.load(std::memory_order_acquire);

item = buffer_[r];

```



### 4.4 批量操作



```cpp

// 一次 enqueue/dequeue 多个元素，摊销 CAS 开销

bool enqueue_batch(const T* items, size_t count);

bool dequeue_batch(T* items, size_t& count);

```



### 4.5 Backoff 策略



```cpp

size_t backoff = 1;

while (!try_enqueue(item)) {

    for (size_t i = 0; i < backoff; ++i) {

        _mm_pause();  // 或 std::this_thread::yield()

    }

    backoff = std::min(backoff * 2, max_backoff);

}

```

## 七、注意事项



1. **无锁并非总是更快**：低竞争场景下，`std::mutex` 可能更高效，因为无锁操作会导致缓存行频繁失效。

2. **不能替代锁的语义**：无锁队列只保证单个操作的原子性，复杂事务仍需锁。

3. **避免在无锁操作中做重活**：入队/出队应该是 O(1) 操作。

4. **内存回收必须慎重**：ABA 问题和悬空指针是最常见的 bug 来源。

5. **测试至关重要**：需要使用 ThreadSanitizer (TSan)、Relacy Race Detector 等工具验证正确性。

6. **优先使用成熟库**：手写无锁数据结构极易出错，生产环境建议使用 Boost.Lockfree 或 moodycamel。

7. **capacity 必须是 2 的幂**（环形缓冲区取模优化场景）。
