### 1、**<span style="color: rgb(143,149,158); background-color: inherit">Lambda初始化捕获：</span>**

在C++14中，lambda表达式的捕获列表支持直接初始化捕获的变量，这意味着可以在定义lambda时直接为捕获的变量赋予初始值，而无需在外部提前声明。例如：auto func = \[y = 2]\() { return y \* 2; };在这里，y是在lambda内部捕获并初始化为2的局部变量。



### 2、**<span style="color: rgb(143,149,158); background-color: inherit">泛型</span> <span style="color: rgb(143,149,158); background-color: inherit">lambda参数</span>**

<span style="color: rgb(143,149,158); background-color: inherit">参数使用auto关键字进行自动推断，使lambda更加灵活和通用。例如：</span>

`auto print = [](const auto& value) { std::cout << value << '\n'; };`

`print(10); // Works for integers`

`print("Hello"); // Works for strings too`

### 3、**<span style="color: rgb(143,149,158); background-color: inherit">constexpr函数的增强</span>**

<span style="color: rgb(143,149,158); background-color: inherit">在C++11中，constexpr函数的限制非常严格，要求其函数体仅能包含一个返回语句，且不能包含复杂的控制流语句（如循环、条件分支等）。</span>

*`// C++11 constexpr阶乘函数的写法，只能使用递归`*
`constexpr int factorial(int n) {`
`    return n <= 1 ? 1 : (n * factorial(n - 1));`
`}`

<span style="color: rgb(143,149,158); background-color: inherit">而在C++14中，允许在其函数体内使用更复杂的控制流结构和</span> <span style="color: rgb(143,149,158); background-color: inherit">局部变量</span> <span style="color: rgb(143,149,158); background-color: inherit">声明，也可以有多个返回语句，只要最终的结果能够在编译时计算得出即可。</span>

`// C++14 constexpr阶乘函数的写法，可以使用循环`

`constexpr int factorial(int n) {`

`    int ret = 0;`

`    for (int i = 0; i < n; ++i) {`

`        ret += i;`

`    }`

`    return ret;`

`}`

### 4、**<span style="color: rgb(143,149,158); background-color: inherit">废弃标志 [[deprecated]]：</span>**

C++14引入了一个标准化的属性(attribute)来标记已弃用的函数、类或其他声明。这有助于编译器在编译时发出警告，提醒开发者不应再使用某个已标记为过时的API。例如：\[\[deprecated("Use newFunction instead, this function will be removed in version 2.0")]]void oldFunction() {// ...}，表示oldFunction已经被弃用了，如有必要请使用对应的api替代。



### 5、**<span style="color: rgb(143,149,158); background-color: inherit">读写锁std::shared_timed_mutex和std::shared_lock：</span>**

C++14扩展了线程支持库，引入了std::shared\_timed\_mutex作为新的互斥量类型，它支持共享（读）锁定和独占（写）锁定。同时，新增了std::shared\_lock类模板，作为一个便捷的共享锁管理器，提供了对std::shared\_timed\_mutex以及其他兼容锁类型的隐式锁定和解锁操作。

### 6、**<span style="color: rgb(143,149,158); background-color: inherit">模板可变整数序列：</span>**

C++14增强了模板元编程的能力，引入了可变参数模板的整数序列表示。这使得在编译时处理整数序列变得更加容易，对于实现各种编译时计算、算法或数据结构非常有用。虽然具体细节未在提供的信息中给出，但这类特性通常涉及到使用类似std::integer\_sequence和std::make\_integer\_sequence等工具类。

### 7、**<span style="color: rgb(143,149,158); background-color: inherit"> std::exchange：</span>**

<span style="color: rgb(143,149,158); background-color: inherit">std::exchange用于原子地交换一个对象的值，并返回其旧值。这个函数在处理资源管理、状态转换等场景时特别有用。</span>

`std::string str = "hello!";`
*`// ret的值为：hello`*
*`// str的值为：hello world!`*
`auto ret = std::exchange(str, "hello world!");`

### 8、**<span style="color: rgb(143,149,158); background-color: inherit">字符串字面值带引号：</span>**

<span style="color: rgb(143,149,158); background-color: inherit">C++14允许在字符串字面值中嵌入单引号、双引号和反斜杠等，无需转义。通过使用R&quot;(…)&quot;语法，可以轻松包含原生字符串，而不必担心转义问题。</span>

*`// rawStr的内容就是：abc\db'\t"`*
`const char* rawStr = R"(abc\db'\t")";`
